# NKS Coaching Center - Online Test Portal (Class 1 to 10)

🌐 **हमारी लाइव वेबसाइट का लिंक (विद्यार्थियों को भेजने के लिए):**
👉 https://github.io

---

### 📌 नया टेस्ट अपलोड करने के 3 आसान नियम:
1. वेबसाइट पर जिस पाठ का टेस्ट जोड़ना है, उसके अंदर जाकर **Test 1 से Test 5** के नीचे लिखा **सटीक फाइल कोड** देखें (जैसे `c10_hin_ch1_t1.html`)।
2. अपनी 50 प्रश्नों वाली HTML फाइल को बिल्कुल उसी नाम से GitHub पर अपलोड करें।
3. इसके बाद `index.html` फाइल खोलें और `const uploaded = [` वाली लिस्ट में उस फाइल का नाम कॉमा लगाकर लिख दें और **Commit changes** दबा दें।

  * **हिंदी (Hindi):** `c10_hin_ch1_t1.html` (पाठ 1 का टेस्ट 1)
